# Changelog

## 0.1.3 — 2026-08-02

- Licensed under GPL-3.0-or-later with SPDX identifiers.

- Added automatic Silent, Balanced, and Performance profile switching.
- Added CPU and dual AMD GPU temperature monitoring.
- Added GPU utilization and per-core system-load awareness.
- Added persistent peak-temperature and fan statistics.
- Added live terminal monitoring with bar graphs.
- Added automatic configuration reload.
- Added emergency maximum-fan and sensor-failure protection.
- Added safe handoff to Apple SMC when the service stops.
